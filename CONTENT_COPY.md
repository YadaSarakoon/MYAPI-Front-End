# MyAPI Branding & Copy Guidelines

## 🎯 Brand Identity

### Brand Mission
**Thai:**
นำเสนออกแบบพื้นฐาน API ที่ทรงพลัง ปลอดภัย และง่ายต่อการใช้งาน เพื่อให้นักพัฒนาและธุรกิจทั่วโลกสามารถเชื่อมต่อระบบของตนได้อย่างรวดเร็วและมั่นใจ

**English:**
Provide powerful, secure, and easy-to-use API infrastructure so developers and businesses worldwide can integrate systems quickly and confidently.

### Brand Voice & Tone

**Characteristics:**
- **Friendly yet Professional** - Approachable but authoritative
- **Clear & Concise** - No jargon, explain technical concepts simply
- **Confident** - Demonstrate expertise and reliability
- **Empathetic** - Understand developer and business pain points
- **Innovative** - Forward-thinking and modern

**Writing Style:**
- Use active voice
- Short sentences (under 15 words when possible)
- Avoid marketing fluff
- Be specific with features and benefits
- Use examples and code snippets
- Address the reader directly ("you", "your")

### Brand Keywords

**Primary:**
- API Platform
- Easy Integration
- Real-time
- Reliable
- Scalable
- Developer-Friendly
- Enterprise-Grade

**Secondary:**
- Logistics
- Shipment Management
- Tracking
- Automation
- Connected Businesses
- Seamless Integration

## ✍️ Tone & Language Patterns

### DO's:
- ✅ Use short, action-oriented sentences
- ✅ Focus on benefits, not features
- ✅ Use specific numbers and metrics
- ✅ Address pain points directly
- ✅ Include social proof (testimonials, user count)
- ✅ Use active voice
- ✅ Be specific with examples

### DON'Ts:
- ❌ Avoid marketing jargon
- ❌ Don't make unsupported claims
- ❌ Avoid vague language
- ❌ Don't use passive voice
- ❌ Avoid too much technical jargon for non-technical sections
- ❌ Don't over-promise

### Example Rewrite:

**Before:**
"MyAPI provides comprehensive API solutions designed to facilitate seamless integration"

**After:**
"Connect your systems to MyAPI in minutes, not days"

## 🌐 Localization Notes

### Thai Language:
- Use "ได้" for capability (e.g., สามารถเชื่อมต่อได้)
- Use "อัตโนมัติ" for automatic/automation
- Use "ที่ดีเยี่ยม" for excellent/great
- Use "ทันที" for immediately/instant
- Keep lines shorter than English (more readable)

### English Language:
- Use present tense for timeless statements
- Use "You can" for capability
- Use "Automatically" for automation
- Be concise but complete
- Vary sentence length
